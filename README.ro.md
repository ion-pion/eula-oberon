# Eula Oberon (pe scurt, în română)

Terminal și compilator Oberon-07 care rulează pe telefonul Android și face aplicații Android direct pe telefon: `apk Modul.Mod "Eticheta"`.
Se instalează o singură dată din Termux: `bash install-eula-oberon.sh`. Exemple: `examples/Cubicum7B18.Mod` (Cubicum 7·B) și `examples/pian.z7l`.
